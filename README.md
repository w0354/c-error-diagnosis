# C 语言错因诊断工作台

这是一个面向 C 语言初学者的错因诊断与复习辅助项目。当前公开版本负责：

- 解析固定格式的九段诊断回答；
- 校验错因类别、知识点和必要字段；
- 展示原题、同类题、正确代码和逐行说明；
- 查看错题记录、待重做题目和错因分布；
- 展示编译检查与运行检查结果。

## 本地运行

```powershell
python -m pip install -r requirements.txt
streamlit run app.py
```

## 当前限制

- 第一版仍需要粘贴诊断回答，尚未接入模型 API。
- Streamlit Community Cloud 的本地文件不能作为长期数据库。
- 新记录和“已重做”状态在云端重启后可能丢失。
